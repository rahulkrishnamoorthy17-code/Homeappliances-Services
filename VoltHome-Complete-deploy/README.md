## Front-end features
Bootstrap 5 responsive layout, local SVG artwork, dark/light theme, RTL/LTR toggle, product search & category filters, blog search & filters, localStorage enquiry cart, working repair booking demo, working contact message demo, warranty checker UI, local registration/login demo and dashboard data rendering.

## Demo store location
The contact map points to the RS Puram area in Coimbatore, Tamil Nadu. Replace the address and OpenStreetMap coordinates with the real client's store location before production use.

## Notes
This is a static HTML template. Contact/booking/login actions use browser localStorage for functional demos. Real production authentication, email delivery, payments, inventory and database operations require a backend/API.
